# oktobuoy's first webpage

A personal webpage made with plain HTML, CSS, and JavaScript. No packages or installation are needed.

- `index.html` holds the page's words and structure.
- `style.css` controls its colors, layout, and appearance.
- `script.js` makes the “Say hello” button work and updates the year.

Open `index.html` in a browser, or serve the folder locally:

```sh
cd /workspace/test
python3 -m http.server 8000 --bind 0.0.0.0
```

Then visit the server in your browser. This does not publish the website online.
